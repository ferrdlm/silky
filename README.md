***silky OS:***

a minimalist, typo focused webOS built with HTML, CSS, and javascript. inspired by macOS aesthetics and clean digital workspaces.


**live demo**

check out the live operating system here: https://silkyos.netlify.app

**features from webOS 1 mission**
- macOS inspired floating Dock: interactive translucent dock with smooth animations
- top bar system: dynamic app indicator, real time clock, and real battery level status.
- draggable windows: custom drag and drop system for modular windows.
- welcome screen (introduction & my links)
- music player (spotify playlist integration)
- quick notes (journaling pad)

***new features from webOS 2 mission***
- system settings app: sidebar navigation with tabs for customizable wallpapers (Gingham Green, Minimal Grey), system specs, and window translucency toggles.
- silky CLI terminal: interactive CLI with supported system commands (`/help`, `/clear`, `/open [app]`, `/date`).
- retro calculator: functional calculator widget integrated directly into the desktop workspace.

**built with**
- HTML5
- CSS3
- javascript (drag API)
